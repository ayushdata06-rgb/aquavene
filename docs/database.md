# AquaVane Database Schema & Spatial Architecture

AquaVane uses a relational PostgreSQL 15+ database with the PostGIS 3.4 spatial extension (hosted on Supabase or locally). All primary keys are UUIDs to support distributed safety, replication, and offline development synchronization.

## 2. Table Specifications

### 2.1 `watersheds`
Core spatial table storing micro-watershed administrative and topological boundaries.
- **`geom`**: PostGIS `MultiPolygon` in WGS 84 (`EPSG:4326`). GiST indexed via `idx_watersheds_geom`.
- **`centroid`**: Pre-computed `Point` (`EPSG:4326`) for rapid map centering and fly-to navigation.
- **`area_sq_km`**: Surface area calculated in projected planar coordinates.

### 2.2 `priority_scores`
Individual micro-watershed scores produced by scoring runs.
- **`overall_score`**: Continuous priority score ($0.0 - 100.0$).
- **`priority_category`**:
  - `Critical`: Score $\ge 75.0$ (urgent intervention needed)
  - `High`: $60.0 \le \text{Score} < 75.0$
  - `Moderate`: $40.0 \le \text{Score} < 60.0$
  - `Low`: Score $< 40.0$
- **Index**: Composite index on `(scoring_run_id, rank_position)` for sub-millisecond leaderboard retrieval.

### 2.3 `saved_plans` (DPR Restoration Proposals)
Stores certified civil engineering restoration plans and Detailed Project Report (DPR) budgets generated by the Simulator.
- **`area_name`**: Target catchment or custom boundary name.
- **`watershed_id`**: Optional reference to a registered micro-watershed (null if created from a custom 4-point AOI).
- **`original_score`** & **`simulated_score`**: Before vs. after restoration urgency scores.
- **`original_soil_loss`** & **`simulated_soil_loss`**: Predicted soil loss reduction (tonnes/ha/year).
- **`reforest_pct`**, **`check_dams_count`**, **`cct_pct`**: User intervention allocations.
- **`budget_lakhs_inr`**: Total civil construction budget estimated in ₹ Lakhs.
- **`interventions_json`**: Structured Bill of Quantities (BoQ) array with intervention titles, quantities, costs, and spatial coordinates.

## 3. Spatial Queries & Performance Indexing

```sql
-- 1. Bounding Box Viewport Queries
SELECT id, watershed_code, name, ST_AsGeoJSON(geom)
FROM watersheds
WHERE geom && ST_MakeEnvelope(:min_lon, :min_lat, :max_lon, :max_lat, 4326);

-- 2. Point-in-Watershed Identification
SELECT id, watershed_code, name
FROM watersheds
WHERE ST_Contains(geom, ST_SetSRID(ST_Point(:lon, :lat), 4326))
LIMIT 1;

-- 3. Area in Square Kilometers
SELECT name, ST_Area(geom::geography) / 1000000.0 AS area_sq_km
FROM watersheds;
```
